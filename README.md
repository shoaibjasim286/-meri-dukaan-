# Meri Dukaan 🏪

Aasan dukaan management app — Pakistani dukaandaron ke liye.

Simple shop management app for Pakistani shopkeepers.

---

## 🇵🇰 Urdu Mein

Ye ek aasan app hai jis se aap apni dukaan ka poora hisaab rakh sakte hain:

- 🛒 **Bikri (Sales)** — customer ko saman bechein, bill banao
- 📦 **Samaan (Products)** — stock track karo, kam hone par alert
- 👥 **Customers** — udhaar (credit) ka hisaab rakho
- 🚚 **Suppliers** — maal kahan se aaya, payment kab di
- 💸 **Kharchay (Expenses)** — roz ke kharche likho
- 💰 **Payments** — customer se paise wasool karo
- ↩️ **Wapsi (Returns)** — customer ne saman wapas kiya to adjust karo
- 📊 **Reports** — din, hafte, mahine ki report dekho
- 🔒 **Staff + PIN** — apne workers ko alag alag permission do

**Kaise chalayen:**
```bash
npm install
npm run dev
```
